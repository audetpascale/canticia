# 🎵 CanticIA

**Cantiques générés par l'Intelligence Artificielle**

Bienvenue sur CanticIA, une collection collaborative et libre de cantiques dont la musique a été créée par l'IA. Tous les cantiques sont distribués sous **Copyleft**, ce qui signifie qu'ils sont libres d'utilisation, de modification et de redistribution.

## 🌟 À propos du Projet

CanticIA est une initiative novatrice qui combine la créativité humaine avec la puissance de l'intelligence artificielle pour produire de la musique sacrée accessible à tous.

### 🎯 Objectifs

- ✅ Créer une collection libre de cantiques
- ✅ Permettre à quiconque d'utiliser, modifier et partager les œuvres
- ✅ Construire une communauté collaborative autour de la musique sacrée
- ✅ Créer des chants sans IA en compilant des contributions humaines

## 🎼 Participer au Projet

### Contribuer vos Stems

Avez-vous des enregistrements audio (stems) d'un cantique ? Nous aimerions les inclure dans notre collection !

**Comment contribuer :**

1. Enregistrez vos stems (voix, instruments, etc.)
2. Envoyez-les à : **canticia@example.com**
3. Incluez le titre du cantique et votre nom
4. Nous ajouterons votre contribution au projet

### Projet Collectif

Quand nous avons suffisamment de stems pour un cantique, nous les mélangerons pour créer une **version complète sans IA**, utilisant uniquement les contributions humaines. C'est une opportunité unique de créer de la musique vraiment collaborative !

## 🔧 Configuration

### Ajouter des Cantiques

Les cantiques sont stockés dans une [feuille Google Sheets](https://docs.google.com/spreadsheets/d/e/2PACX-1vTPJnCPB9Y0jj85Pbc_X-dqRug4jh6gYN2OsWsDps5XaJbGtV7edqPruJe88nkYSmYuPoG6xZjCD4PN/pub?output=csv).

**Colonnes requises :**
- `Titre` : Titre du cantique
- `Artiste` : Nom de l'artiste/créateur
- `Description` : Courte description
- `Tags` : Catégories (séparées par virgule)
- `Liens` : Liens externes (format: "Nom:URL|Nom:URL")

## 💻 Développement Local

1. Clonez le repository :
```bash
git clone https://github.com/audetpascale/canticia.git
cd canticia
```

2. Ouvrez `index.html` dans votre navigateur

Ou utilisez un serveur local :
```bash
python -m http.server 8000
```

Alors visitez `http://localhost:8000`
